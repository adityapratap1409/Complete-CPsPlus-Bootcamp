# Complete C++ Learning Journey

Welcome to my repository tracking my progress through C++ programming and Data Structures & Algorithms. This repository serves as a personal log of foundational logic, problem-solving techniques, and competitive programming problems.

---

## Repository Structure

* **Basics**: Data types, variables, operators, input/output, and type casting.
* **Conditionals**: Decision-making logic using if-else constructs and switch statements.
* **For Loops**: Iterative control flow, execution logic, and loop counters.
* **While Loops**: Conditional iteration and pattern-printing problems.
* **Bitwise Operators and Operator Properties**: Bitwise AND, OR, XOR, NOT, bit shifts, operator precedence, and variable scope.
* **Functions**: Modular code development, pass-by-value vs. pass-by-reference, and function parameters.
* **Arrays**: Array initialization, linear search, binary search, array manipulation, and optimal algorithms (e.g., duplicate finder using XOR).
* **LeetCode-Questions**: Structured implementations of LeetCode DSA problems categorized by topic.
